## 3. 模块详细设计

### 3.1 首页概要模块
**职责**：展示首页基础统计、双主视角概要卡、热点标签并提供跳转入口。  
**输入**：当前用户、当前生效版本、首页摘要接口结果。  
**输出**：首页渲染结果和跳转参数。  
**关键状态**：loading / normal / partial_empty / empty / error。  
**测试重点**：摘要统计正确性、热点标签跳转、权限裁剪。

### 3.2 技术要素模块
**职责**：承接业务部门主视角分析，提供技术要素/技术方向下的统计与分布结果。  
**页面组成**：筛选区、概要统计、国家分布、院校分布、人才明细。  
**关键流程**：加载筛选项 → 恢复路由参数 → 构建 Query Context → 请求概要统计和当前 Tab 数据 → 详情/收藏/入池。  
**测试重点**：筛选联动、统计与列表一致、下钻行为、空态和异常态。

### 3.3 国家院校模块
**职责**：承接平台部门主视角分析，提供区域/国家/学校下的覆盖与技术要素分布。  
**页面组成**：筛选区、概要统计、院校分布、技术要素分布、人才明细。  
**关键流程**：加载区域/国家/学校 → 恢复跳转参数 → 构建 Query Context → 拉取统计和列表。  
**测试重点**：区域/国家/学校联动、技术要素分布口径、热点跳转。

### 3.4 搜索模块
**职责**：提供跨视角统一搜索。  
**页面组成**：高级筛选区、结果列表区、分页区。  
**关键流程**：录入条件 → 查询 → 排序/分页 → 操作结果。  
**测试重点**：组合查询、排序重置、与其他页面结果口径一致。

### 3.5 人才详情模块
**职责**：展示单人才详情和招聘判断信息，承接运营动作。  
**页面组成**：基础信息、技术标签、学术摘要、招聘摘要、成果、操作区。  
**关键流程**：权限校验 → 拉取详情 → 执行收藏/备注/状态更新。  
**测试重点**：字段完整性、直链越权、操作状态回显。

### 3.6 收藏与人才池模块
**职责**：管理收藏、人才池、备注和跟进状态。  
**关键流程**：校验对象可见性 → 执行收藏/入池/备注/状态保存 → 局部刷新。  
**测试重点**：状态一致性、重复收藏幂等、权限变化后降级处理。

### 3.7 权限管理模块
**职责**：配置页面权限和学校/国家/技术要素资源范围，并维护默认视角。  
**测试重点**：角色分层、多维资源权限、默认视角与权限不冲突。

### 3.8 采集配置模块
**职责**：管理采集范围和采集策略。  
**测试重点**：范围白名单、策略参数保存、高危权限控制。

### 3.9 采集任务与数据版本模块
**职责**：手动触发任务、查看任务结果、生成候选版本、发布和回滚。  
**测试重点**：任务状态流转、版本唯一 current live、发布失败不影响线上。

### 3.10 数据质量与轻量纠偏模块
**职责**：展示质量摘要并支持关键字段纠偏。  
**测试重点**：摘要数字正确性、纠偏留痕、版本生效口径。

## 4. 模块依赖关系

### 4.1 前台依赖
- 首页概要模块依赖技术要素模块和国家院校模块的摘要能力。
- 技术要素模块、国家院校模块和搜索模块都依赖人才详情模块。
- 人才详情模块依赖收藏与人才池模块承接后续动作。

### 4.2 后台依赖
- 采集配置模块是任务模块的上游。
- 任务与版本模块是质量模块的上游。
- 权限管理模块对所有后台模块形成访问控制边界。
