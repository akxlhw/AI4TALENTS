# 13B_页面原型与交互设计说明（学术人才子系统 MVP v1.1）

**文档名称**：页面原型与交互设计说明（学术人才子系统 MVP v1.1）
**文档编号**：13B
**版本**：V1.1
**状态**：冻结版
**适用范围**：智能人才库—学术人才子系统 MVP v1.1

---

## 1. 设计原则

1. 采用成熟企业级 Web 风格，不照抄参考图。  
2. 适度使用玻璃风格，但不得影响可读性。  
3. 搜索仍是重要入口。  
4. 首页不做重分析，只做概览和入口。  
5. 技术要素和国家院校两个主视角必须并行清晰。  
6. 学生视图偏表格，教授视图偏卡片。  
7. 热点标签要轻量，不能做成复杂大屏。

---

## 2. 首页

### 2.1 页面定位
首页是统一入口页，承接：
- 全局基础统计
- 搜索主入口
- 技术要素概要入口
- 国家院校概要入口

### 2.2 页面结构
1. 页面标题与数据版本信息  
2. 基础统计卡片区  
3. 搜索区  
4. 主视角概要区  
5. 辅助信息区（可选）

### 2.3 基础统计卡片
建议展示：
- 已收录高校数
- 教授类人才数
- 学生类人才数
- 总人才数
- 授权学校数

### 2.4 搜索区
包含：
- 关键词输入框
- 搜索按钮
- 可选快捷筛选：技术要素、国家、学校

### 2.5 主视角概要区

#### 技术要素概要卡
展示：
- 技术要素数
- 技术方向数
- 人才总数
- 覆盖国家数
- 覆盖院校数

底部展示：
- 热门技术要素标签
- 进入技术要素按钮

#### 国家院校概要卡
展示：
- 覆盖国家数
- 覆盖院校数
- 人才总数
- 覆盖技术要素数

底部展示：
- 主要国家标签（按人才数Top5）
- Top院校机构标签（按人才数Top5）
- 进入国家院校按钮

### 2.6 交互说明
- 点击技术要素概要卡或按钮进入技术要素页
- 点击热门技术要素标签带参进入技术要素页
- 点击国家院校概要卡或按钮进入国家院校页
- 点击主要国家或Top院校机构标签带参进入国家院校页
- 热点标签数据通过API实时获取，按人才数排序

## 3. 技术要素页

### 3.1 页面定位
业务部门主页面，从技术要素/技术方向视角展示人才列表。

### 3.2 页面结构
1. 标题与当前条件区
2. 概要统计区
3. 筛选区
4. 人才列表区

### 3.3 数据加载逻辑

#### 3.3.1 页面初始化
1. **获取用户权限范围**：根据当前用户角色，获取其可查看的技术要素范围、学校范围、国家范围
2. **加载总体概览数据**：默认显示用户权限范围内所有数据的总体统计，无需用户手动选择
   - 概要统计区显示权限范围内的人才总数、教授数、学生数、覆盖国家数、覆盖院校数、技术方向数
   - 人才列表显示权限范围内所有人才
3. **筛选区下拉框**：技术要素、技术方向下拉框仅显示用户权限范围内的选项

#### 3.3.2 用户筛选
1. 用户可通过筛选区选择特定技术要素/方向/国家/学校等条件
2. 选择筛选条件后点击"查询"，概要统计区和人才列表更新为筛选后的结果
3. 点击"重置"恢复为用户权限范围内的总体数据

#### 3.3.3 权限控制要点
- 管理员（super_admin/admin）：可查看所有数据
- 普通用户：仅可查看其权限范围内的数据
  - 技术要素范围：下拉框仅显示授权的技术要素
  - 国家范围：统计数据和列表仅包含授权国家的人才
  - 学校范围：统计数据和列表仅包含授权学校的人才

### 3.4 筛选区
- 技术要素（下拉框，选项受权限控制）
- 技术方向（下拉框，根据所选技术要素动态更新）
- 关键词
- 国家
- 学校
- 人才角色
- 查询 / 重置

### 3.5 概要统计区
- 人才总数
- 教授数
- 学生数
- 覆盖国家数
- 覆盖院校数
- 技术方向数

### 3.6 人才列表
- 表格形式展示人才明细
- 支持点击查看人才详情

## 4. 院校机构页

### 4.1 页面定位
平台部门主页面，以区域为第一分类维度展示院校机构。

### 4.2 页面结构
1. 标题与当前条件区
2. 概要统计区
3. 筛选区
4. 院校列表区（按区域分组）

### 4.3 区域分类
院校按以下区域进行分类展示：
- **北美地区**：美国、加拿大等
- **亚太地区**：中国、日本、韩国、新加坡、澳大利亚等
- **欧洲地区**：英国、德国、法国、瑞士、荷兰、意大利、西班牙、瑞典等
- **其他**：不属于以上三大区域的国家

### 4.4 筛选区
- 区域（亚太/欧洲/北美/其他）
- 国家
- 关键词

### 4.5 概要统计区
- 人才总数
- 教授数
- 学生数
- 覆盖院校数

### 4.6 结果展示
- 按区域分组展示院校表格
- 优先展示人才数较多的院校机构
- 点击院校可跳转到院校详情页

### 4.7 数据加载逻辑

#### 4.7.1 页面初始化
1. **获取用户权限范围**：根据当前用户角色，获取其可查看的国家范围、学校范围
2. **加载总体概览数据**：默认显示用户权限范围内所有数据的总体统计
3. **按区域分组显示院校**：院校按亚太、欧洲、北美、其他四大区域分组展示

#### 4.7.2 用户筛选
1. 用户可通过筛选区选择特定区域/国家
2. 关键词支持院校名称搜索
3. 点击"重置"恢复为全部数据

## 8. 后台页面

### 8.1 采集配置管理页

#### 设计理念（简化版 MVP v1.1）
采集配置管理采用简化设计，核心逻辑：**技术要素 → 顶会顶刊 → 采集任务**

**固定参数（无需配置）：**
- 数据类型：学者、论文、机构
- 时间范围：2010.1.1 至今

**可配置参数：**
- 技术要素关联的顶会顶刊列表
- 采集模式：全量/增量

#### 页面结构
两个Tab页：
1. 技术要素配置
2. 采集任务

#### 技术要素配置Tab
- 表格展示所有技术要素
- 每行显示：技术要素名称、关联顶会顶刊（标签形式）、顶会顶刊数量、最后采集时间
- 操作按钮：
  - 「配置」：弹窗编辑关联的顶会顶刊
  - 「采集」：启动采集任务（未配置顶会顶刊时禁用）

#### 采集任务Tab
- 表格展示采集任务记录
- 每行显示：任务编码、技术要素、采集模式、状态、进度、记录数、触发时间
- 操作按钮：查看详情、取消（仅执行中任务）

#### 启动采集弹窗
确认信息展示：
- 采集范围：关联的顶会顶刊列表
- 数据类型：学者、论文、机构（固定）
- 时间范围：2010.1.1 至今（固定）
- 采集模式：全量/增量（单选）

### 8.2 数据版本与发布页
表格展示版本列表，支持查看摘要、发布和回滚。

### 8.3 数据质量与纠偏页
卡片 + 列表，展示质量摘要和待确认项，支持轻量纠偏。

## 9. 页面交互通用要求

1. 所有页面都应有 loading、empty、error 三类状态。  
2. 跳转参数应尽量恢复页面上下文。  
3. 列表页操作后应局部刷新，不刷新全页。  
4. 权限不足时应展示安全友好的无权限提示或空态。  
5. 字号、间距、标题层级必须清晰，避免页面过密。
