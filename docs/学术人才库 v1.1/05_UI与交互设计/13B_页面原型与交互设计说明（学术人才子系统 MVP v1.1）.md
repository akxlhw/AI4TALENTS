# 13B_页面原型与交互设计说明（学术人才子系统 MVP v1.1）

**文档名称**：页面原型与交互设计说明（学术人才子系统 MVP v1.1）  
**文档编号**：13B  
**版本**：V1.0  
**状态**：冻结版  
**适用范围**：智能人才库—学术人才子系统 MVP v1.1

---

## 1. 设计原则

1. 采用成熟企业级 Web 风格，不照抄参考图。  
2. 适度使用玻璃风格，但不得影响可读性。  
3. 搜索仍是重要入口。  
4. 首页不做重分析，只做概览和入口。  
5. 技术要素和国家院校两个主视角必须并行清晰。  
6. 学生视图偏表格，教授视图偏卡片。  
7. 热点标签要轻量，不能做成复杂大屏。

---

## 2. 首页

### 2.1 页面定位
首页是统一入口页，承接：
- 全局基础统计
- 搜索主入口
- 技术要素概要入口
- 国家院校概要入口

### 2.2 页面结构
1. 页面标题与数据版本信息  
2. 基础统计卡片区  
3. 搜索区  
4. 主视角概要区  
5. 辅助信息区（可选）

### 2.3 基础统计卡片
建议展示：
- 已收录高校数
- 教授类人才数
- 学生类人才数
- 总人才数
- 授权学校数

### 2.4 搜索区
包含：
- 关键词输入框
- 搜索按钮
- 可选快捷筛选：技术要素、国家、学校

### 2.5 主视角概要区

#### 技术要素概要卡
展示：
- 技术要素数
- 技术方向数
- 人才总数
- 覆盖国家数
- 覆盖院校数

底部展示：
- 热门技术要素标签
- 进入技术要素按钮

#### 国家院校概要卡
展示：
- 覆盖国家数
- 覆盖院校数
- 人才总数
- 覆盖技术要素数

底部展示：
- 重点国家标签
- 重点院校标签
- 进入国家院校按钮

### 2.6 交互说明
- 点击技术要素概要卡或按钮进入技术要素页
- 点击热门技术要素标签带参进入技术要素页
- 点击国家院校概要卡或按钮进入国家院校页
- 点击重点国家或重点院校标签带参进入国家院校页

## 8. 后台页面

### 8.1 采集范围配置页
表格为主，支持新增、编辑、启停、备注。

### 8.2 采集策略配置页
表单 + 列表模式，支持调度周期、模式和执行参数配置。

### 8.3 采集任务管理页
表格展示任务记录，支持手动触发任务。

### 8.4 数据版本与发布页
表格展示版本列表，支持查看摘要、发布和回滚。

### 8.5 数据质量与纠偏页
卡片 + 列表，展示质量摘要和待确认项，支持轻量纠偏。

---

## 9. 页面交互通用要求

1. 所有页面都应有 loading、empty、error 三类状态。  
2. 跳转参数应尽量恢复页面上下文。  
3. 列表页操作后应局部刷新，不刷新全页。  
4. 权限不足时应展示安全友好的无权限提示或空态。  
5. 字号、间距、标题层级必须清晰，避免页面过密。
