# 智能人才库 - 用户操作手册

**文档版本**：V1.0
**适用对象**：招聘团队成员、试用用户
**系统版本**：学术人才子系统 MVP V1.0
**编写日期**：2026年3月20日

---

## 📖 手册说明

### 手册目的
本手册旨在帮助招聘团队成员快速上手使用智能人才库系统，掌握核心功能的使用方法，提高人才发现与评估效率。

### 系统定位
智能人才库是一套面向招聘团队的内部工具，主要功能包括：
- **学术人才发现**：基于OpenAlex学术数据库的人才搜索
- **人才画像查看**：查看学者的研究成果、合作网络等信息
- **候选人筛选与排序**：按多种维度筛选和排序候选人
- **重点人才导出**：导出有价值的候选人列表

### 使用前准备
1. **账号申请**：联系系统管理员获取登录账号
2. **权限说明**：根据您的招聘领域，系统会分配相应的学校访问权限
3. **浏览器要求**：推荐使用 Chrome 90+ 或 Edge 90+ 浏览器

## 🔍 核心功能详解

### 1. 人才搜索功能

#### 1.1 基本搜索
1. 在顶部搜索框中输入关键词（如研究方向、学者姓名、机构名称等）
2. 点击搜索按钮或按Enter键
3. 系统将显示相关的人才列表

**搜索技巧**：
- 使用英文关键词效果更佳（系统数据源为英文）
- 可以搜索具体技术方向，如："machine learning"、"computer vision"
- 可以搜索学者姓名，如："Yoshua Bengio"
- 可以搜索机构名称，如："MIT"、"Stanford"

#### 1.2 高级筛选
在搜索结果页面，您可以使用左侧筛选面板进行精确筛选：

| 筛选条件 | 说明 | 使用建议 |
|----------|------|----------|
| **国家** | 按国家筛选 | 聚焦特定国家的人才 |
| **学校** | 按学校筛选 | 关注目标院校的候选人 |
| **角色类型** | 教授/学生/毕业生 | 根据招聘需求选择 |
| **研究方向** | 按技术方向筛选 | 匹配岗位技术要求 |
| **活跃度** | 按学术活跃度筛选 | 关注近期有产出的学者 |
| **成果数量** | 按论文/专利数量筛选 | 识别高产学者 |

### 2. 人才详情查看

#### 2.1 查看人才基本信息
点击搜索结果中的任意人才卡片，进入详情页面：

**基本信息区包含**：
- 姓名、照片（如有）
- 当前职位和机构
- 研究兴趣和方向
- 联系方式（邮箱、个人主页等）

#### 2.2 查看学术成果
在详情页的"学术成果"标签页中，您可以查看：
- **发表论文**：按时间倒序排列的论文列表
- **合作网络**：展示该学者与其他学者的合作关系
- **引用情况**：论文被引用次数和趋势
- **专利与项目**：相关的专利和科研项目信息

#### 2.3 查看合作关系图
系统会可视化展示学者的合作网络：
- **中心节点**：当前学者
- **连接节点**：合作过的其他学者
- **连线粗细**：表示合作紧密程度
- **点击节点**：查看合作学者的基本信息

### 3. 候选人管理

#### 3.1 收藏候选人
在人才详情页点击"收藏"按钮，将候选人加入您的收藏夹。
- 收藏的候选人可以在"我的收藏"页面统一查看
- 支持添加备注，记录关注原因或下一步计划

#### 3.2 对比候选人
1. 在人才列表页面勾选2-4名候选人
2. 点击"对比"按钮
3. 系统将以表格形式展示候选人的关键信息对比

**对比维度包括**：
- 基本信息（机构、职位、国家）
- 学术产出（论文数、引用数、H指数）
- 研究方向匹配度
- 合作网络规模

#### 3.3 导出候选人
1. 在搜索结果或收藏夹中勾选需要导出的候选人
2. 点击"导出"按钮
3. 选择导出格式（CSV/Excel）
4. 系统将生成包含选中候选人信息的文件

**导出内容包含**：
- 基本信息（姓名、机构、职位、联系方式）
- 学术指标（论文数、引用数、H指数）
- 研究方向和关键词
- 系统内的个人主页链接

### 4. 学校目录浏览

#### 4.1 按国家浏览
1. 点击首页的"国家目录"
2. 选择目标国家
3. 查看该国所有已收录高校列表
4. 点击学校名称进入学校详情页

#### 4.2 学校详情页
在学校详情页中，您可以查看：
- **学校基本信息**：名称、所在国家、简介
- **人才统计**：该校教授数、学生数、毕业生数
- **人才列表**：按角色类型筛选查看该校人才
- **研究方向分布**：该校学者的主要研究领域

## 📊 实用场景指南

### 场景1：寻找特定技术方向的专家
**目标**：招聘人工智能领域的教授

**操作步骤**：
1. 在搜索框输入 "artificial intelligence" 或 "AI"
2. 在筛选面板选择"角色类型：教授"
3. 按"成果数量"排序，找到高产学者
4. 查看详情，关注其研究方向和最新成果
5. 将合适的候选人加入收藏夹或直接导出

### 场景2：挖掘有潜力的博士生/博士后
**目标**：招聘有潜力的年轻研究人员

**操作步骤**：
1. 在筛选面板选择"角色类型：学生"或"毕业生"
2. 按"活跃度"排序，关注近期有产出的学者
3. 查看合作网络，识别与知名教授合作的学生
4. 关注研究方向与公司技术路线的匹配度
5. 批量导出候选名单，进行进一步评估

### 场景3：了解目标院校的人才分布
**目标**：了解麻省理工学院（MIT）的计算机领域人才

**操作步骤**：
1. 通过学校目录找到"Massachusetts Institute of Technology"
2. 进入学校详情页
3. 在筛选条件中选择"研究方向：Computer Science"
4. 查看人才列表，按角色类型分组查看
5. 导出该校相关领域的所有人才信息

### 场景4：跟踪关注学者的最新动态
**目标**：定期跟踪已关注学者的最新成果

**操作步骤**：
1. 将关注的学者加入收藏夹
2. 每周登录系统，查看"我的收藏"页面
3. 关注系统提示的"最近更新"信息
4. 点击学者卡片查看是否有新发表的论文
5. 根据最新成果更新评估笔记

## ⚡ 效率提升技巧

### 1. 快捷键使用
| 快捷键 | 功能 | 适用页面 |
|--------|------|----------|
| **Ctrl+F** | 快速聚焦搜索框 | 所有页面 |
| **/ (斜杠)** | 快速搜索 | 所有页面 |
| **Esc** | 关闭弹窗/取消操作 | 所有页面 |
| **Enter** | 确认搜索/打开详情 | 搜索页、列表页 |

### 2. 批量操作技巧
- **批量选择**：在列表页面使用Shift+点击进行连续选择，Ctrl+点击进行多选
- **批量导出**：选择多个候选人后，一次导出全部信息
- **批量对比**：选择2-4名候选人进行对比分析

### 3. 个性化设置
- **列表列自定义**：在列表页面点击"设置"图标，选择要显示的列
- **默认排序**：在搜索页面设置您常用的排序方式（如按成果数量降序）
- **筛选条件保存**：常用筛选组合可以保存为"搜索模板"

## ❓ 常见问题解答 (FAQ)

### Q1: 搜索时为什么有些学者找不到？
**A**: 可能的原因包括：
- 学者信息尚未被OpenAlex收录
- 学者姓名在不同数据库中的拼写差异
- 您的搜索权限限制（只能访问授权学校的人才）
- 尝试使用英文姓名、研究方向关键词等不同搜索方式

### Q2: 数据更新频率是多少？
**A**:
- **学术数据**：每月同步一次OpenAlex最新数据
- **系统信息**：实时更新用户操作产生的数据（如收藏、备注等）
- 如需特定学者的最新信息，可联系管理员手动触发更新

### Q3: 如何申请更多学校的访问权限？
**A**:
1. 联系您的团队主管说明需求
2. 主管审批后向系统管理员提交申请
3. 管理员将在1-2个工作日内配置权限
4. 您将收到权限开通通知

### Q4: 导出的数据可以用于哪些用途？
**A**:
- 内部招聘评估和讨论
- 候选人沟通前的背景了解
- 招聘数据分析和报告
- 禁止将数据用于商业用途或向外部泄露

### Q5: 遇到系统错误或功能问题怎么办？
**A**: 请按以下步骤处理：
1. 截图记录错误现象
2. 记录操作步骤和错误时间
3. 通过以下渠道反馈：
   - 企业微信联系系统管理员
   - 发送邮件至 talent-support@内部邮箱
   - 紧急问题直接电话联系

## 🔒 使用规范与注意事项

### 1. 数据使用规范
- 系统数据仅限于内部招聘工作使用
- 不得将数据用于商业分析、学术研究等非招聘用途
- 尊重学者隐私，不得滥用联系方式进行骚扰
- 导出数据需妥善保管，防止泄露

### 2. 账号安全要求
- 账号密码定期更换（建议90天）
- 不得将账号借给他人使用
- 离职或岗位变动时及时通知管理员注销账号
- 发现账号异常立即联系管理员

### 3. 操作注意事项
- 批量导出大量数据时，尽量选择非工作时间
- 添加备注时避免记录敏感信息或个人隐私
- 使用对比功能时，注意保护候选人信息
- 系统操作日志会被记录，请规范操作
