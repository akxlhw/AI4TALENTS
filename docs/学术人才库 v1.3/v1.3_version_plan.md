## 二、架构升级方案

### 2.1 数据库层升级

#### PostgreSQL 迁移 (P0)

**迁移策略**:
1. 开发环境保持 SQLite 支持（便于本地开发）
2. 生产环境强制 PostgreSQL
3. 使用环境变量切换数据库驱动

**关键配置**:
```python
# 生产环境建议配置
pool_size=20          # 连接池大小
max_overflow=40       # 最大溢出连接
pool_pre_ping=True    # 连接健康检查
statement_cache_size=0  # 禁用语句缓存（PgBouncer 兼容）
```

**迁移文件调整**:
- 现有 Alembic 迁移需兼容 PostgreSQL
- 新增 PostgreSQL 特有索引（部分索引、表达式索引）

#### 索引优化 (P0)

**新增复合索引**:

```sql
-- 人才列表查询优化
CREATE INDEX ix_talent_school_role_visible
ON core_talent(school_id, role_type, is_visible)
INCLUDE (talent_id, name, h_index);

-- 技术标签筛选优化
CREATE INDEX ix_tech_tag_element_enabled
ON core_talent_tech_tag(tech_element_id, is_enabled)
INCLUDE (talent_id, tech_direction_id);

-- 国家筛选优化
CREATE INDEX ix_school_country_active
ON core_school(country_code, is_visible);

-- 标准化层查询优化
CREATE INDEX ix_std_author_cs_score
ON std_author(cs_concepts_score)
WHERE cs_concepts_score >= 0.5;
```

### 2.2 缓存层建设 (P1)

#### Redis 缓存策略

| 数据类型 | 缓存键前缀 | TTL | 更新策略 |
|----------|-----------|-----|----------|
| 首页统计 | `stats:home` | 5min | 采集完成刷新 |
| 技术要素统计 | `stats:tech:{code}` | 5min | 写时失效 |
| 国家分布 | `stats:country` | 10min | 写时失效 |
| 人才详情 | `talent:{id}` | 30min | 写时失效 |
| 学校详情 | `school:{id}` | 30min | 写时失效 |

**缓存穿透保护**:
- 空结果缓存 1 分钟
- Bloom Filter 预判

**缓存击穿保护**:
- 热点数据永不过期
- 分布式锁重建

### 2.3 服务层优化 (P1)

#### 批量操作重构

**当前问题**: 单条处理，频繁 commit

**优化方案**:
```python
# 批量 upsert 示例
async def bulk_sync_authors(self, std_authors: list[StdAuthor]):
    talent_dicts = [self._to_talent_dict(a) for a in std_authors]

    stmt = insert(Talent).values(talent_dicts)
    stmt = stmt.on_conflict_do_update(
        index_elements=['source_record_id'],
        set_={k: stmt.excluded[k] for k in talent_dicts[0].keys()}
    )

    await self.session.execute(stmt)
    await self.session.commit()
```

**预期收益**: 同步性能提升 5-10x

#### 游标分页实现

**当前**: OFFSET 分页，深分页性能差

**优化**: 游标分页
```python
# 基于 last_id 的游标分页
async def get_talents_by_cursor(
    self,
    cursor: int | None = None,  # last_id
    limit: int = 20
):
    query = select(Talent).order_by(Talent.talent_id.desc())
    if cursor:
        query = query.where(Talent.talent_id < cursor)
    return await self.session.scalars(query.limit(limit))
```

## 四、技术选型

| 组件 | 当前方案 | v1.3 方案 | 说明 |
|------|----------|-----------|------|
| 数据库 | SQLite/PostgreSQL | PostgreSQL 必选 | 生产环境 |
| 缓存 | 无 | Redis | 缓存层 |
| 连接池 | SQLAlchemy 内置 | SQLAlchemy + asyncpg | PostgreSQL 异步驱动 |
| 前端缓存 | 无 | @tanstack/react-query | 请求缓存 |
| 日志 | print + logging | structlog | 结构化日志 |
| 监控 | 无 | Prometheus + Grafana | 指标采集 |
