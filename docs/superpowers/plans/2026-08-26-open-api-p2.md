# 开放 API P2（三域导入端点 + 跨域统一搜索）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 开放竞赛/实验室/行业三域 JSONL 导入端点（`<域>:write` scope），并以注册表模式提供跨域统一人才搜索（不破坏跨域隔离铁律）。

**Architecture:** shared 定义 `UnifiedTalentSummary` + `SearchProvider` 协议与模块级注册表；各域在自己 services 内实现 Provider 并由 `api/open_api.py` 导入触发注册（域→shared 合法，shared 不反向导入域）。搜索路由在 shared，按 `domains` 查询参数动态校验各域 `:read` scope，`asyncio.wait_for` 并行 + 单域失败降级。导入端点收 raw JSONL body（≤20MB），复用各域现有导入 Service 与审计。

**Tech Stack:** FastAPI + asyncio（gather/wait_for）+ 既有 JSONL 导入服务

**设计文档:** `docs/superpowers/specs/2026-08-26-open-api-design.md`（P2 部分）

统一摘要模型与注册表：

```python
# registry.py
"""Cross-domain search registry (inversion: domains register, shared consumes)."""

from __future__ import annotations

from typing import Any, Protocol

from pydantic import BaseModel, Field


class UnifiedTalentSummary(BaseModel):
    """Domain-agnostic talent summary for /open-api/search aggregation."""

    domain: str
    talent_id: int
    name: str
    identifier: str | None = None  # github_login / handle
    url: str | None = None         # public profile page (PII redacted per domain)
    tags: list[str] = Field(default_factory=list)


class SearchProvider(Protocol):
    domain: str

    async def search(self, keyword: str, limit: int) -> list[UnifiedTalentSummary]: ...


_REGISTRY: dict[str, SearchProvider] = {}


def register_search_provider(provider: Any) -> None:
    _REGISTRY[provider.domain] = provider


def get_search_providers(domains: list[str] | None = None) -> list[SearchProvider]:
    if not domains:
        return list(_REGISTRY.values())
    return [_REGISTRY[d] for d in domains if d in _REGISTRY]


def registered_domains() -> list[str]:
    return sorted(_REGISTRY)
```

`require_valid_api_key`（无 scope，端点内按查询参数动态校验）：

```python
# open_api_auth.py 追加
def require_valid_api_key() -> Any:
```

### Task 2: 跨域统一搜索端点（TDD，fake providers）

**Files:**

- Modify: `backend/app/api_router.py`（挂载）
- Test: `backend/tests/domains/shared/test_open_api_search.py`

```python
# open_api_search.py 核心逻辑
_GET = require_valid_api_key()
_PER_DOMAIN_CAP = 20
_TIMEOUT_SECONDS = 5.0

@router.get("/talents", tags=["Open API — Search"])
async def unified_search(
    keyword: str = Query(..., min_length=1, max_length=200),
    domains: str | None = Query(None, description="逗号分隔，如 academic,open_source；缺省=全部已注册域"),
    per_domain: int = Query(5, ge=1, le=_PER_DOMAIN_CAP),
    principal: dict = Depends(_GET),
) -> dict:
    wanted = [d.strip() for d in domains.split(",") if d.strip()] if domains else None
    providers = get_search_providers(wanted)
    unknown = [d for d in (wanted or []) if d not in registered_domains()]
    missing_scopes = [p.domain for p in providers if f"{p.domain}:read" not in principal["scopes"]]
    if missing_scopes:
        raise HTTPException(403, f"API key lacks read scope for: {', '.join(missing_scopes)}")

    async def _run(p):
        return await asyncio.wait_for(p.search(keyword, per_domain), timeout=_TIMEOUT_SECONDS)

    results = await asyncio.gather(*[_run(p) for p in providers], return_exceptions=True)
    items, errors = [], {}
    for p, r in zip(providers, results):
        if isinstance(r, Exception):
            errors[p.domain] = str(r)[:200]
        else:
            items.extend([s.model_dump(mode="json") for s in r])
    return {"keyword": keyword, "domains": [p.domain for p in providers],
            "unknown_domains": unknown, "items": items, "errors": errors}
```

测试要点：无 Key 401；缺某域 read scope 403 并列名；正常聚合 fake providers；单域抛错降级进 `errors` 且其余域正常；`unknown_domains` 透出。

注册模式（每域相同）：

```python
# services/open_api_provider.py
class AcademicSearchProvider:
    domain = "academic"

    async def search(self, keyword: str, limit: int) -> list[UnifiedTalentSummary]:
        talents, _ = await TalentService(session).search_talents_basic(keyword, page_size=limit)
        ...
```

Provider 持有 session：构造时传入（endpoint 侧为每次请求构造 provider 实例）→ 注册表保存的是**工厂**而非单例。修正协议：`register_search_provider(domain, factory)`，factory 签名 `(session) -> SearchProvider`；endpoint 中 `provider = factory(session)` 后调用。

集成测试：注册工厂后，用种子数据（academic + open_source 各 1 行）经真实端点验证聚合与 PII 剔除。

统一模式（scope `<域>:write`，raw body，≤20MB，审计 event_subtype="import"）：

```python
@router.post("/import", summary="…JSONL 导入（scope: <域>:write）")
async def import_xxx(
    request: Request,
    <域特有 Query 参数>,
    session: AsyncSession = Depends(get_async_session),
    principal: dict = Depends(require_api_key("<域>:write")),
):
    raw = await request.body()
    if len(raw) > 20 * 1024 * 1024:
        raise HTTPException(413, "Body too large (max 20 MB)")
    content = raw.decode("utf-8")  # UnicodeDecodeError → 400
    report = await <ImportService>(session).import_jsonl(content, <参数>)
    await session.commit()
    await AuditService.log_data_operation(
        user_id=None, operation="import", resource_type="<域>_talent",
        status="success", detail={"principal": principal["key_name"], "report": …摘要}, event_subtype="import")
    return report
```

- industry：`position_id: int` 必填 + `batch: str | None`；`IndustryImportService.import_jsonl(content, position_id=position_id, batch=batch)`
- competition：无额外参数；`CompImportService.import_jsonl(content)`；`CompImportError` → 400
- lab：`parent_lab: str` 必填；`LabImportService.import_jsonl(content, parent_lab)`

测试：401/403 门禁 ×3；happy path ×3（复用 lab `_person` / comp `_meta+_series+_contest+person` / industry `_VALID_JSONL` 夹具）；无效 UTF-8 → 400。
