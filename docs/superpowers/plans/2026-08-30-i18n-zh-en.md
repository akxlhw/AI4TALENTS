# V5.1.1 中英文切换（i18n）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** react-i18next 基础设施 + 顶栏切换器 + 全局骨架与高频用户页面的中英双语文案，默认中文、localStorage 记忆。

**Architecture:** i18next 单例为语言事实源（localStorage 持久化）；antd ConfigProvider 的 locale 经 `useTranslation().i18n.language` 联动（无新全局 store）；资源按命名空间拆分于 `src/i18n/locales/{zh,en}/`。覆盖范围外页面保持中文硬编码（设计文档附录登记）。

**Tech Stack:** i18next + react-i18next + antd locale（zhCN/enUS）+ Vitest

**设计文档:** `docs/superpowers/specs/2026-08-30-i18n-zh-en-design.md`

**迁移纪律（适用于所有页面迁移任务）**：
1. key 命名：`<ns>.<区块>.<元素>`，如 `academic.search.placeholder`、`common.actions.export`
2. 中文原文进 `zh/<ns>.json`，英文翻译遵循 `taxonomy` 术语表
3. 组件内 `const { t } = useTranslation('<ns>')`；跨命名空间 `useTranslation(['common','<ns>'])` 后 `t('common.x')`
4. 动态插值用 i18next 参数：`t('x.total', { n: total })` ↔ `"total": "共 {{n}} 条"`
5. 每完成一个域：`npx tsc -b` + 该域涉及组件的既有测试修正 + 提交

describe('i18n init', () => {
  beforeEach(() => localStorage.clear())

  it('defaults to zh and restores persisted language', async () => {
    localStorage.setItem('i18n_lang', 'en')
    const { i18n } = await import('./index') // re-eval not guaranteed; see init API below

})

- [ ] **Step 4: 实现 i18n 初始化与首批资源**

`frontend/src/i18n/index.ts`：

```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'

import authEn from './locales/en/auth.json'
import commonEn from './locales/en/common.json'
import navEn from './locales/en/nav.json'
import authZh from './locales/zh/auth.json'
import commonZh from './locales/zh/common.json'
import navZh from './locales/zh/nav.json'

export const LANG_STORAGE_KEY = 'i18n_lang'
export const SUPPORTED_LANGS = ['zh', 'en'] as const
export type Lang = (typeof SUPPORTED_LANGS)[number]

const initialLang: Lang = (() => {
  const saved = localStorage.getItem(LANG_STORAGE_KEY)
  return saved === 'en' ? 'en' : 'zh'
})()

i18n.use(initReactI18next).init({
  resources: {
    zh: { common: commonZh, nav: navZh, auth: authZh },
    en: { common: commonEn, nav: navEn, auth: authEn },
  },
  lng: initialLang,
  fallbackLng: 'zh',
  defaultNS: 'common',
  ns: ['common', 'nav', 'auth'],
  interpolation: { escapeValue: false },
})

// Keep localStorage in sync on every switch (switcher and tests both go through here)
i18n.on('languageChanged', lng => {
  localStorage.setItem(LANG_STORAGE_KEY, lng)
})

export default i18n
```

import { useTranslation } from 'react-i18next'

const LanguageSwitcher: React.FC = () => {

      size="small"
      value={i18n.language === 'en' ? 'en' : 'zh'}
