> 竞赛人才域 v1.0 —— 域结构、数据流、表设计、迁移与索引

## 2. 实体关系

```
comp_series (赛事系列) 1 ──< comp_contest (赛事实例) 1 ──< comp_result (成绩) >── 1 comp_talent (选手)
   codeforces                  Round #951 (Div.1)         tourist 第 1 名          handle=tourist
   icpc                        2024 World Finals          Team A 金牌              （跨平台暂不合并，
   atcoder                     ABC 380                    rating 3904→3948          unified_person_id 预留）

comp_team (队伍) 1 ──< comp_result
   "World Champion Team"  ←────  某场 ICPC 中该队的成绩，选手经 result.team_id + team_members 关联
```

- `comp_series`：赛事品牌/系列（codeforces、icpc、ioi、imc、ctf、kaggle、robocup、asc/sc/isc…），由爬虫 `type: series` 行 upsert，也可种子预置
- `comp_contest`：一场具体比赛（某年某场），`(source_code, external_id)` 唯一
- `comp_talent`：选手，`(source_code, lower(handle))` 唯一
- `comp_team`：队伍（团队赛核心单元），`(source_code, lower(name))` 唯一；队员以 `comp_result.team_members` 明细落到具体场次
- `comp_result`：某选手（个人赛）或某队伍（团队赛）在某场比赛的成绩；个人成绩 `(talent_id, contest_id)` 唯一，团队成绩 `(team_id, contest_id)` 唯一

## 3. 表设计（DDL 级）

### 3.1 `comp_series` — 赛事系列

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| series_id | Integer | PK, autoincrement | |
| code | String(50) | **unique, index, not null** | 机器码：`codeforces` / `icpc` / `atcoder` / `noi` / `kaggle` / `mcm` / `ctf` |
| name | String(255) | not null | 展示名（中文） |
| name_en | String(255) | nullable | 英文名 |
| homepage | String(500) | nullable | 官网 |
| description | String(2000) | nullable | 简介 |
| logo_url | String(1000) | nullable | 系列 logo |
| is_enabled | Boolean | not null, default true | 前端是否展示 |
| created_at / updated_at | DateTime | TimestampMixin | |

### 3.2 `comp_contest` — 赛事实例

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| contest_id | Integer | PK, autoincrement | |
| series_id | Integer | FK(comp_series.series_id), index, not null | |
| source_code | String(50) | not null, index | 冗余 series.code（去重键的一部分，避免 join） |
| external_id | String(100) | not null | 源站赛事 ID（Codeforces contestId、AtCoder abc380） |
| name | String(500) | not null | 赛事名（如 "Codeforces Round 951 (Div. 1)"） |
| start_time | DateTime | nullable, index | 开赛时间（UTC） |
| duration_seconds | Integer | nullable | 时长 |
| season | String(50) | nullable, index | 赛季/年份（如 "2024"、"ICPC 2024-2025"） |
| status | String(20) | not null, default "finished" | finished / ongoing / upcoming |
| source_url | String(1000) | nullable | 源站榜单页 |
| raw_meta | JSON | nullable | 源站原始附加字段（phase/type/frozen 等） |
| created_at / updated_at | DateTime | TimestampMixin | |
| — | **UniqueConstraint(source_code, external_id)** | | 幂等去重键 |

### 3.3 `comp_talent` — 选手

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| talent_id | Integer | PK, autoincrement | |
| handle | String(255) | not null, index | 平台账号（大小写保留原始，去重用 lower） |
| handle_lower | String(255) | not null, index | lower(handle)，查询/去重统一走此列 |
| source_code | String(50) | not null, index | 归属平台（该记录来自哪个源） |
| real_name | String(255) | nullable | 真实姓名（源站提供才有） |
| school | String(255) | nullable, index | 学校/组织（Codeforces organization） |
| country_code | String(10) | nullable, index | 国家/地区码（ISO 两字母） |
| avatar_url | String(1000) | nullable | 头像 |
| profile_url | String(1000) | nullable | 源站个人主页 |
| current_rating | Integer | nullable, index | 当前积分（导入时按最新成绩重算） |
| max_rating | Integer | nullable | 历史最高积分 |
| rank_title | String(50) | nullable, index | 段位（Codeforces: Legendary Grandmaster…；其他源各自档位） |
| global_rank | Integer | nullable | 平台活跃榜排名（源站提供才有） |
| contests_count | Integer | not null, default 0 | 参赛场次（聚合） |
| medals_gold / medals_silver / medals_bronze | Integer | not null, default 0 | 奖牌计数（按 result.award 聚合） |
| specialties | JSON | nullable | 专长标签列表（源站 tags 或后续分析产出） |
| last_contest_at | DateTime | nullable, index | 最近参赛时间（活跃度） |
| dedup_hash | String(64) | **unique, not null, index** | `md5(source_code + ":" + handle_lower)` |
| unified_person_id | String(100) | nullable, index | 预留：跨平台身份合并 |
| is_visible | Boolean | not null, default true | |
| created_at / updated_at | DateTime | TimestampMixin | |
| — | **UniqueConstraint(source_code, handle_lower)** | | 与 dedup_hash 二选一，建议两者都建（查询走组合键，写入走 hash） |

### 3.4 `comp_result` — 比赛成绩

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| result_id | Integer | PK, autoincrement | |
| talent_id | Integer | FK(comp_talent.talent_id), index, nullable | 个人成绩归属（个人赛必填，团队赛可空） |
| team_id | Integer | FK(comp_team.team_id), index, nullable | 团队成绩归属（团队赛必填，个人赛可空） |
| contest_id | Integer | FK(comp_contest.contest_id), index, not null | |
| rank | Integer | nullable | 名次（榜单类必有；参与类可空） |
| score | Float | nullable | 得分（ACM 为过题数可放 problem_count+penalty 到 raw_meta） |
| rating_before / rating_after | Integer | nullable | 赛后积分变动（Codeforces oldRating/newRating） |
| award | String(20) | nullable, index | gold / silver / bronze / hm(荣誉提名) / none |
| team_name | String(255) | nullable | 队伍名原文（冗余展示；实体关联走 team_id） |
| team_members | JSON | nullable | 本场队员明细 `[{handle?, real_name, role?}]`（团队赛把成员落到具体场次） |
| source_url | String(1000) | nullable | 该成绩源站链接 |
| raw_meta | JSON | nullable | 源站原始行（party/penalty 等） |
| created_at / updated_at | DateTime | TimestampMixin | |
| — | **UniqueConstraint(talent_id, contest_id)** | | 个人成绩一人一场一条（talent_id 非空时） |
| — | **UniqueConstraint(team_id, contest_id)** | | 团队成绩一队一场一条（team_id 非空时） |
| — | CheckConstraint: `talent_id IS NOT NULL OR team_id IS NOT NULL` | | 至少归属一方 |

### 3.5 `comp_team` — 队伍（团队赛单元）

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| team_id | Integer | PK, autoincrement | |
| source_code | String(50) | not null, index | 来源赛事系列 |
| name | String(255) | not null | 队名（原始大小写） |
| name_lower | String(255) | not null, index | lower(name)，去重/查询用 |
| school | String(255) | nullable, index | 学校/组织（ICPC/超算的学校队） |
| country_code | String(10) | nullable, index | 国家/地区码 |
| logo_url | String(1000) | nullable | 队徽/校徽 |
| dedup_hash | String(64) | **unique, not null, index** | `md5(source_code + ":" + name_lower + ":" + coalesce(school,""))` |
| created_at / updated_at | DateTime | TimestampMixin | |
| — | **UniqueConstraint(source_code, name_lower, school)** | | 同源同名校队唯一 |

> 队员不落 team 表：团队赛队伍随场次变动大（ICPC 每年重组），成员关系按场次落在 `comp_result.team_members`，选手个人仍归 `comp_talent`（有 handle 时）。

### 3.6 索引汇总

| 表 | 索引 |
|----|------|
| comp_series | code(unique) |
| comp_contest | (source_code, external_id) unique、series_id、start_time、season |
| comp_talent | dedup_hash unique、(source_code, handle_lower) unique、current_rating、country_code、school、last_contest_at |
| comp_team | dedup_hash unique、(source_code, name_lower, school) unique、country_code |
| comp_result | (talent_id, contest_id) unique、(team_id, contest_id) unique、contest_id、award |

前端高频查询：选手列表按 rating 倒序（`current_rating DESC NULLS LAST` + `country_code` 等值 + `handle_lower LIKE`）；赛事榜单按 `(contest_id, rank)`。

## 4. 迁移

- Alembic 单 revision：`create_competition_tables`，建 5 表 + 上述约束/索引
- `app/model_registry.py` 注册后 `make migrate-create msg="add competition domain tables"`
- 种子（M1）：`scripts/data/seed_comp_series.py` 预置系列——`codeforces`（M1 启用）、`icpc` / `ioi` / `imo` / `ipho` / `imc` / `ctf` / `kaggle` / `robocup` / `asc` / `sc` / `isc` / `atcoder`（按 00 文档分期逐个放开，`is_enabled` 控制前端展示；`icho`/`ibo` 暂缓不预置）

## 5. 与既有三域的关系

| 关注点 | 结论 |
|--------|------|
| 跨域身份 | 不合并；`unified_person_id` 预留（同 lab） |
| 收藏/对比 | 本期不支持（lab 同）；后续如做，按域独立表（`favourites` 已有 open_source 先例） |
| 权限 | 登录即可读；导入 `require_super_admin`（与 lab 导入一致） |
| 指标/日志 | 复用 `app.core.metrics`、采集日志走 `logging_context.current_task_id` 同款模式（导入任务包一层 contextvar） |
| 首页 | `homepage` 域统计暂不含竞赛（M2 再进首页，避免跨域查询） |
