# 34_MVP v1.1 测试增补清单

**文档名称**：MVP v1.1 测试增补清单  
**文档编号**：34  
**版本**：V1.0  
**状态**：冻结版  
**适用范围**：智能人才库—学术人才子系统 MVP v1.1

---

## 1. 文档说明

本文件用于在 v1.0 测试基线之上，明确 v1.1 新增和增强能力所对应的增补测试范围。  
它不是替代 24B，而是补充说明“哪些测试点是 v1.1 特有的、必须新增覆盖的”。

---

## 2. 增补测试总原则

1. 新增页面必须完整测试，不只做冒烟。  
2. 增强页面必须做回归测试，尤其是首页、搜索、详情。  
3. 涉及热点标签、概要统计、版本发布和权限裁剪的功能，必须重点检查口径一致。  
4. 后台高危操作必须覆盖无权限角色的拦截场景。  
5. 所有新增状态值和状态切换都应纳入测试。

---

## 3. v1.1 新增测试主题

### 3.1 首页双主视角
- 技术要素概要卡展示
- 国家院校概要卡展示
- 热门技术要素标签展示与跳转
- 重点国家 / 重点院校标签展示与跳转
- 首页摘要权限裁剪

### 3.2 技术要素页
- 技术要素 / 技术方向联动
- 国家分布正确性
- 院校分布正确性
- 人才明细正确性
- 从首页带参进入后的默认筛选恢复
- 同一筛选条件下统计与列表一致

### 3.3 国家院校页
- 区域 / 国家 / 学校联动
- 技术要素分布正确性
- 从首页带参进入后的默认筛选恢复
- 同一筛选条件下统计与列表一致

### 3.4 搜索增强
- 多条件组合查询
- 新增筛选条件生效
- 重置逻辑
- 结果操作（收藏 / 入池）
- 权限裁剪

### 3.5 详情增强
- 技术标签显示
- 招聘判断摘要显示
- 数据完整度显示
- 待确认项显示
- 详情页运营动作

### 3.6 轻量运营
- 收藏创建/取消
- 人才池创建与加人
- 备注保存
- 跟进状态修改
- 收藏对象后续权限变更后的降级处理

### 3.7 后台采集与发布
- 范围配置新增/编辑/启停
- 策略配置新增/编辑/启停
- 手动触发任务
- 任务状态流转
- 候选版本生成
- 手动发布
- 当前生效版本切换

### 3.8 数据质量与纠偏
- 质量摘要展示
- 纠偏动作
- 纠偏留痕
- 纠偏后的结果生效口径

### 3.9 权限扩展
- 学校、国家、技术要素三维资源权限
- 首页热点权限
- 详情直链越权
- 导出权限

## 4. 增补回归范围

### 4.1 首页回归
- 基础统计仍正确
- 搜索入口仍可用
- 页面视觉层级不退化

### 4.2 原学校链路回归
- 学校页仍可进入
- 学校页到列表页再到详情页链路不受 v1.1 破坏

### 4.3 搜索回归
- 原关键词搜索链路正常
- 分页与排序正常
- 异常态和空态正常

### 4.4 权限回归
- 原学校范围权限不失效
- 无权限页面和对象继续拦截有效

---

## 5. 优先级建议

### P0 必测
- 首页双主视角
- 技术要素页
- 国家院校页
- 搜索增强
- 详情增强
- 权限扩展
- 版本发布链路

### P1 应测
- 收藏与人才池
- 数据质量摘要
- 轻量纠偏
- 导出留痕

### P2 可增强
- 更多异常态细节
- 长列表和更多排序组合
- 多角色默认视角组合

---

## 6. 结论

本清单用于确保 v1.1 不会在 v1.0 原测试集上“漏掉新增点”。  
实际测试执行时，应与 `24B_测试与验收用例说明` 配合使用：
- 24B 负责完整测试设计
- 34 负责 v1.1 相对 v1.0 的增补覆盖提醒
