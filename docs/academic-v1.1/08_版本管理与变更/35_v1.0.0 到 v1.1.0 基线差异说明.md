# 35_v1.0.0 到 v1.1.0 基线差异说明

**文档名称**：v1.0.0 到 v1.1.0 基线差异说明  
**文档编号**：35  
**版本**：V1.0  
**状态**：冻结版  
**适用范围**：智能人才库—学术人才子系统

---

## 1. 说明目的

本文件用于清晰说明学术人才子系统从 `v1.0.0-mvp-baseline` 升级到 `v1.1.0` 时的主要变化，便于：
- 项目内部汇报
- 业务评审
- 研发交底
- 测试验收说明
- 版本发布说明

---

## 2. 版本定位差异

### v1.0.0 定位
学校维度的学术人才基础浏览库。重点解决：
- 基础数据展示
- 关键词搜索
- 按国家 / 学校浏览
- 学校信息页
- 人才列表与详情
- 基础权限控制

### v1.1.0 定位
面向研发招聘的技术要素与国家院校双视角人才发现与轻量运营平台。重点解决：
- 技术要素视角看人才供给
- 国家院校视角看人才覆盖
- 首页双主视角概要入口
- 收藏/人才池/备注/跟进状态
- 数据采集与发布后台
- 权限扩展到国家与技术要素维度

---

## 3. 页面差异

| 模块 | v1.0.0 | v1.1.0 |
| --- | --- | --- |
| 首页 | 基础统计 + 搜索 + 学校总览倾向 | 基础统计 + 搜索 + 技术要素概要 + 国家院校概要 + 热点标签 |
| 技术要素 | 无 | 新增页面，业务部门主视角 |
| 国家院校 | 无 | 新增页面，平台部门主视角 |
| 人才搜索 | 基础搜索 | 组合筛选增强 |
| 人才详情 | 基础信息与学术展示 | 新增技术标签、招聘摘要、完整度与待确认项 |
| 我的收藏 | 基础或弱化 | 增强为轻量运营入口 |
| 采集配置后台 | 无或弱 | 新增范围配置、策略、任务、版本、质量 |

---

## 4. 业务视角差异

### v1.0.0
以“国家 / 学校 / 人才”链路为主，适合基础浏览和演示。业务部门若想看“某技术方向的人才覆盖”，需要通过学校或搜索结果间接推断。

### v1.1.0
形成两个明确主视角：

#### 技术要素
技术要素 → 技术方向 → 国家 / 学校 / 人才  
适合业务部门快速判断“我的业务方向有多少人”。

#### 国家院校
区域 → 国家 → 学校 → 技术要素 / 人才  
适合平台团队快速判断“我的区域覆盖了哪些学校和方向”。

---

## 5. 首页差异

### v1.0.0
首页偏系统总览和资源入口。

### v1.1.0
首页升级为统一入口页，新增：
- 技术要素概要卡
- 国家院校概要卡
- 热门技术要素
- 重点国家 / 院校
- 双主视角跳转

首页不再承担重分析，而是承担“概览 + 决定下一步进入哪个视角”。

---

## 6. 搜索与详情差异

### 搜索
v1.0.0 搜索条件较少，以关键词和基础维度为主。  
v1.1.0 新增：
- 技术要素
- 技术方向
- 区域
- 国家
- 学校
- 人才角色
- 是否已毕业
- 待确认状态

### 详情
v1.0.0 详情偏资料页。  
v1.1.0 详情偏招聘判断页，新增：
- 技术标签
- 主方向 / 次方向
- 招聘判断摘要
- 数据完整度
- 待确认项
- 收藏 / 入池 / 备注 / 跟进状态

---

## 7. 运营能力差异

### v1.0.0
主要支持浏览和少量基础操作。

### v1.1.0
新增轻量运营闭环：
- 收藏
- 人才池
- 备注
- 跟进状态

系统从“只看人才”升级为“可继续跟进人才”。

---

## 8. 数据运营差异

### v1.0.0
数据更多是静态接入和展示。

### v1.1.0
新增后台数据运营能力：
- 采集范围配置
- 自动采集周期配置
- 全量 / 增量模式
- 采集任务列表
- 数据版本生成
- 手动发布控制
- 数据质量摘要
- 轻量人工纠偏

系统从“展示数据”升级为“可控地运营数据”。

---

## 9. 权限差异

### v1.0.0
以学校范围权限为主。

### v1.1.0
扩展为：
- 学校范围
- 国家范围
- 技术要素范围
- 默认视角

并要求权限作用到：首页统计、热点标签、搜索结果、详情页、导出和后台操作。

---

## 10. 实施方式差异

### v1.0.0
以 MVP 首版建设为主。

### v1.1.0
以基线冻结后的增量迭代为主，建议在 `feature/mvp-1.1-*` 分支中分模块推进，最终形成：
- `v1.1.0-mvp-enhanced`

---

## 11. 升级结论

从 `v1.0.0-mvp-baseline` 升级到 `v1.1.0`，系统完成的不是简单加页面，而是**产品视角与系统能力的双升级**：
- 从学校维度浏览升级为双主视角发现
- 从只读资料页升级为轻量运营平台
- 从静态展示升级为可控数据后台
- 从单维权限升级为多维资源权限

v1.1 使学术人才子系统更贴近真实研发招聘使用场景，也为后续其他人才子系统扩展提供了更稳的基础。
