## 5. Phase 4: 语言聚合 (aggregate_languages.py)

**目标**: 按开发者聚合语言熟练�?
**算法**:
1. 遍历所有贡献记录的语言分布

3. 上限 10.0（防止仓库过多导致分数爆炸）

```python
for lang, bytes_count in languages.items():
    total_bytes = sum(languages.values())
    proportion = bytes_count / total_bytes if total_bytes > 0 else 0
    dev_skills[login][lang]["proficiency_score"] += proportion
    dev_skills[login][lang]["repo_count"] += 1

# Cap at 10.0
for skill in sorted_skills:
    skill["proficiency_score"] = min(skill["proficiency_score"], 10.0)
```
