# V5.0.0 — 行业人才库

> 版本：V5.0.0 | 状态：开发中

---

## 1. 版本概述

V5.0.0 的核心交付物是**行业人才库**（`domains/industry/`），AI4TALENT 的第四个人才域。

行业人才库的数据来源是 `smart-talent-sourcing` skill 产出的脉脉/LinkedIn 候选人数据（三维打分 JSONL），通过管理员导入进入系统。

### 版本范围

| 交付物 | 说明 |
|--------|------|
| 行业人才库后端 | `domains/industry/` 独立域，三表模型（岗位 + 人才 + 关联表） |
| JSONL 导入服务 | 增量 upsert，支持 skill 推送 + 管理员上传 |
| 岗位管理 | 系统配置里的岗位 CRUD（含部门/技术方向/职级范围） |
| 前端人才列表 | 以人才为主的卡片网格 + 筛选（与学术/AI Native 库一致体验） |
| 前端人才详情 | 基本信息 + 履历时间线 + 多岗位匹配分对比 |
| 导航集成 | 主导航新增"行业人才"入口，紫色域主题 |

### 不在本次范围

- 跨库同一性识别（预留字段）
- 后端重打分（打分由 skill 完成）
- JD LLM 解析
- 向量嵌入/语义搜索

## 3. 关键决策记录

| # | 决策 | 理由 | 日期 |
|---|------|------|------|
| 1 | 岗位是一等实体（独立表） | 按岗招聘是核心原则，岗位有生命周期 | 2026-08-01 |
| 2 | 人才全局唯一（dedup_hash = name + current_org + current_title 三要素） | 同一人才可命中多个岗位；防 org 缺失时同名合并 | 2026-08-01 |
| 3 | 打分存在关联表 | 同人对不同岗位匹配分不同 | 2026-08-01 |
| 4 | 增量 upsert 导入（非全量替换） | 保留用户编辑的 touched/status/notes | 2026-08-01 |
| 5 | 技术方向关联 core_tech_direction | 技术领域太粗，方向才是岗位精度 | 2026-08-01 |
| 6 | 职级用数字范围（level_min/max） | 华为式职级序列（如 19-20 级） | 2026-08-01 |
| 7 | 前端以人才为主（非岗位为主） | 与全库一致的人才发现体验 | 2026-08-01 |
