# 部署指南

## 环境要求

- Windows 10/11 或 Windows Server 2019+
- Python 3.11+
- Node.js 20+ (前端)
- PostgreSQL 16+ (推荐 16，有预编译 pgvector)
- pgvector 扩展 (v1.4 语义搜索功能必需)
- Redis 7+ (可选，用于缓存加速)
- Visual Studio Build Tools (仅 PostgreSQL 17/18 需要，用于编译 pgvector)

## PostgreSQL 版本选择

| PostgreSQL 版本 | pgvector 支持 | 说明 |
|----------------|--------------|------|
| 16.x | ✅ 推荐 | 有预编译 pgvector 二进制 |
| 15.x | ✅ 支持 | 有预编译 pgvector 二进制 |
| 14.x | ✅ 支持 | 有预编译 pgvector 二进制 |
| 17.x+ | ⚠️ 需自行编译 | 需安装 Visual Studio Build Tools |

## 快速部署

### 1. 安装 PostgreSQL

下载地址: https://www.postgresql.org/download/windows/

或使用 winget:
```powershell
winget install PostgreSQL.PostgreSQL
```

安装时设置 `postgres` 用户密码。

### 2. 安装 pgvector 扩展

#### 方式一：PostgreSQL 16 预编译版（推荐）

1. 下载 pgvector 预编译版本：https://github.com/pgvector/pgvector/releases
2. 解压后将文件复制到 PostgreSQL 安装目录：
   - `vector.dll` → `D:\Program Files\PostgreSQL\16\lib\`
   - `vector.control`, `vector--*.sql` → `D:\Program Files\PostgreSQL\16\share\extension\`

#### 方式二：PostgreSQL 17/18 从源码编译

1. 安装 **Visual Studio Build Tools**：https://visualstudio.microsoft.com/visual-cpp-build-tools/
   - 勾选："使用 C++ 的桌面开发"
2. 克隆并编译：
   ```cmd
   git clone https://github.com/pgvector/pgvector.git
   cd pgvector
   set PG_CONFIG=D:\Program Files\PostgreSQL\18\bin\pg_config.exe
   nmake /F Makefile.win
   nmake /F Makefile.win install
   ```

#### 验证 pgvector 安装

打开 **pgAdmin 4**，连接到目标数据库，打开 Query Tool 执行：

```sql
CREATE EXTENSION vector;
SELECT * FROM pg_extension WHERE extname = 'vector';
```

### 3. 创建数据库

打开 **pgAdmin 4**，连接到 PostgreSQL 服务器后执行以下操作：

#### 3.1 创建用户

1. 右键点击服务器 → **Query Tool**
2. 执行 SQL：

```sql
CREATE USER talent_user WITH PASSWORD 'ai4recruit';
```

#### 3.2 创建生产数据库

1. 右键点击 **Databases** → **Create** → **Database**
2. Database 填写：`talent_db`
3. Owner 选择：`talent_user`
4. 点击 **Save**

或在 Query Tool 中执行：

```sql
CREATE DATABASE talent_db OWNER talent_user;
GRANT ALL PRIVILEGES ON DATABASE talent_db TO talent_user;
```

#### 3.3 授予 schema 权限

1. 选择 `talent_db` 数据库
2. 打开 **Query Tool**
3. 执行：

```sql
GRANT ALL ON SCHEMA public TO talent_user;
```

#### 3.4 启用 pgvector 扩展

在 `talent_db` 的 Query Tool 中执行：

```sql
CREATE EXTENSION vector;
```

### 4. 创建测试数据库

测试需要独立的数据库，避免影响生产数据。

1. 右键点击 **Databases** → **Create** → **Database**
2. Database 填写：`talent_db_test`
3. Owner 选择：`talent_user`
4. 点击 **Save**

或在 Query Tool 中执行：

```sql
CREATE DATABASE talent_db_test OWNER talent_user;
```

### 5. 配置后端

```powershell
cd backend

# 创建虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate

# 安装依赖 (使用国内镜像加速)
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 复制配置文件
copy .env.example .env
```

编辑 `.env` 文件，确认数据库连接：
```
DATABASE_URL=postgresql+asyncpg://talent_user:ai4recruit@localhost:5432/talent_db
DATABASE_SYNC_URL=postgresql://talent_user:ai4recruit@localhost:5432/talent_db
```

### 6. 运行数据库迁移

```powershell
cd backend
.\.venv\Scripts\Activate
alembic upgrade head
```

### 7. 初始化系统数据

```powershell
# 完整初始化 (包含用户、技术要素、顶刊顶会)
python scripts/init_system.py --full --force
```

### 8. 配置 Redis (可选，推荐生产环境启用)

Redis 用于缓存首页统计数据和搜索结果，可大幅提升性能。

#### 8.1 安装 Redis

**Windows 方式一：使用 Memurai (推荐)**
```powershell
winget install Memurai.Memurai
```

**Windows 方式二：使用 WSL**
```bash
sudo apt install redis-server
sudo service redis-server start
```

#### 8.2 配置 Redis

编辑 `backend/.env`:
```env
REDIS_URL=redis://localhost:6379/0
REDIS_ENABLED=true
REDIS_PASSWORD=          # 如需密码认证
REDIS_MAX_CONNECTIONS=10
CACHE_DEFAULT_TTL=300    # 缓存 5 分钟
```

#### 8.3 验证 Redis 连接

```powershell
redis-cli ping
# 应返回: PONG
```

### 9. 配置 LLM (语义搜索和 JD 匹配必需)

v1.4 核心功能依赖 LLM：
- **语义搜索**: 将搜索词和学者资料转为向量，支持语义匹配
- **JD 岗位匹配**: 解析岗位描述，自动匹配研究方向

#### 9.1 选择 LLM 提供商

| 提供商 | LLM_PROVIDER | API Base URL | 说明 |
|--------|-------------|--------------|------|
| DeepSeek | deepseek | https://api.deepseek.com/v1 | 推荐，性价比高 |
| OpenAI | openai | https://api.openai.com/v1 | 国际首选 |
| 智谱 AI | zhipu | https://open.bigmodel.cn/api/paas/v4 | 国产替代 |
| 通义千问 | qwen | https://dashscope.aliyuncs.com/compatible-mode/v1 | 阿里云 |

#### 9.2 配置 LLM

编辑 `backend/.env`:
```env
# 启用 LLM 功能
LLM_ENABLED=true
LLM_PROVIDER=deepseek
LLM_API_KEY=sk-xxxxxxxxxxxxxxxx

# 模型选择
LLM_MODEL=deepseek-chat
LLM_EMBEDDING_MODEL=deepseek-embedding

# 向量维度 (根据模型调整)
EMBEDDING_DIMENSION=1536
```

#### 9.3 测试 LLM 连接

启动后端后访问: http://localhost:8003/api/v1/llm/test

### 10. 生成向量嵌入 (语义搜索必需)

如果启用了语义搜索，需要为现有学者生成向量嵌入：

```powershell
cd backend
.\.venv\Scripts\Activate
python scripts/generate_embeddings.py
```

此步骤会：
1. 获取所有学者的研究方向和论文信息
2. 调用 LLM Embedding API 生成向量
3. 存储到 `core_talent_embedding` 表

### 11. 启动服务

**后端:**
```powershell

.\.venv\Scripts\Activate
uvicorn app.main:app --host 0.0.0.0 --port 8003 --reload
```

**前端:**
```powershell
cd frontend
npm install
npm run dev
```

### 12. 访问系统

- 前端: http://localhost:2012
- 后端 API: http://localhost:8003
- API 文档: http://localhost:8003/docs

默认账号: `admin` / `admin123`

## 常见问题

### 数据库连接失败

1. 确认 PostgreSQL 服务正在运行:
   ```powershell
   Get-Service -Name 'postgresql*'
   ```

2. 检查密码是否正确，在 pgAdmin 中重置：
   - 打开 pgAdmin，连接到数据库
   - 打开 Query Tool，执行：
   ```sql
   ALTER USER talent_user WITH PASSWORD 'ai4recruit';
   ```

### 迁移失败

如果迁移中断，在 pgAdmin 中重置数据库后重试：

1. 选择 `talent_db` 数据库
2. 打开 Query Tool，执行：
```sql
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
GRANT ALL ON SCHEMA public TO talent_user;
```

3. 重新运行迁移：
```powershell
cd backend
.\.venv\Scripts\Activate
alembic upgrade head
```

### 顶刊顶会数据缺失

运行初始化脚本时会自动创建。如果需要单独恢复：
```powershell
python scripts/restore_venues.py
```

## 生产环境高级配置

### 日志轮转

后端使用结构化 JSON 日志，建议配置日志轮转避免磁盘占满。

**Python 日志配置** (`backend/app/core/logging_config.py`):
- 日志文件位置：`backend/logs/`
- 建议每日轮转，保留 30 天

**Windows 日志清理脚本** (`cleanup_logs.ps1`):
```powershell
# 保留最近 30 天的日志
Get-ChildItem -Path "D:\AI\Talent AI Agent\backend\logs" -Filter "*.log" |
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-30) } |
    Remove-Item -Force
```

### 数据库连接池调优

编辑 `backend/.env`，根据服务器配置调整：
```env
# 异步连接池 (asyncpg)
# 小内存服务器 (4GB): 10-20
# 中等服务器 (8GB): 20-40
# 大内存服务器 (16GB+): 40-80
DATABASE_POOL_SIZE=20
DATABASE_MAX_OVERFLOW=40
```

**PostgreSQL 服务器优化** (`postgresql.conf`):
```ini
# 共享内存（建议设置为内存的 25%）
shared_buffers = 2GB

#  effective_cache_size（建议设置为内存的 50-75%）
effective_cache_size = 4GB

# 工作内存（复杂查询时临时使用）
work_mem = 16MB

# 维护操作内存（VACUUM、CREATE INDEX 等）
maintenance_work_mem = 512MB

# 最大连接数
max_connections = 200
```

### 数据备份策略

**每日自动备份脚本** (`backup_db.ps1`):
```powershell
$date = Get-Date -Format "yyyyMMdd_HHmmss"
$backupDir = "D:\Backups\TalentDB"

if (!(Test-Path $backupDir)) {
    New-Item -ItemType Directory -Path $backupDir -Force
}

# 使用 pg_dump 备份
& "D:\Program Files\PostgreSQL\16\bin\pg_dump.exe" `
    -h localhost `
    -U talent_user `
    -d talent_db `
    -F c `
    -f "$backupDir\talent_db_$date.dump"

# 保留最近 14 天的备份
Get-ChildItem -Path $backupDir -Filter "*.dump" |
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-14) } |
    Remove-Item -Force

Write-Host "Backup completed: $backupDir\talent_db_$date.dump"
```

**创建 Windows 计划任务**:
```powershell
# 每天凌晨 2 点执行备份
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-File D:\AI\Talent AI Agent\backup_db.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At "02:00"
Register-ScheduledTask -TaskName "TalentDB_DailyBackup" -Action $action -Trigger $trigger
```

### Redis 生产配置

**持久化配置** (`redis.conf`):
```ini
# 开启 AOF 持久化
appendonly yes
appendfsync everysec

# 内存上限（根据服务器调整）
maxmemory 512mb
maxmemory-policy allkeys-lru

# 绑定内网 IP（不要暴露到公网）
bind 127.0.0.1
```
