| slow 标记测试 | 5 个（默认跳过） |
| **覆盖率报告** | **❌ 无** |

**关键缺陷**：项目未配置覆盖率报告，无法量化测试健康度。建议在 CI 和 `make test-backend` 中追加 `--cov=app --cov-report=term-missing`。

### 3.2 测试有效性

**Repository 测试流于形式**：
- `test_sync.py`、`test_cs_score.py`、`test_collect.py` 大量使用 mock session
- Repository 测试未真实操作数据库，实际测试价值有限
- **建议**：将 Repository 测试改为使用 `test_session` + 真实数据库；Service 测试至少保留 1-2 个集成路径

**SQLite 与生产不一致**：
- `test_models.py` 和 `open_source/test_models.py` 使用 SQLite
- 与生产 PostgreSQL 类型不一致，可能掩盖类型相关问题
- **建议**：统一改为 PostgreSQL async 测试，复用 `test_session`

### 3.3 测试盲区

以下核心模块**无对应测试**：
- `app/middleware/` — 限流、请求日志、指标采集中间件
- `app/domains/academic/services/collect/` 各 phase 文件
- `app/domains/shared/repositories/` — user_repository、permissions 等

### 3.4 测试性能

| 指标 | v2.0.0 | v2.0.1 |
|------|--------|--------|
| 全量测试耗时 | ~25 min | **~9 min** |
| setup 时间 | ~2.0s/test | **~0.5s/test** |
| 优化手段 | DROP/CREATE | TRUNCATE + 全局初始化标记 |

### 3.5 CI 环境缺陷

**PostgreSQL 缺少 pgvector**：
```yaml
services:
  postgres:
    image: postgres:15  # 缺少 pgvector
```

**影响**：CI 中 `requires_pgvector` 的 10 个测试会被跳过。

**修复建议**：
```yaml
services:
  postgres:
    image: pgvector/pgvector:pg15
```

**slow 测试在 CI 中从不执行**：
- `pytest.ini` 默认 `-m "not slow"`
- `test_migrations.py` 6 个测试被标记为 slow，CI 中从不执行
- **建议**：CI 中增加单独的 `pytest -m slow` job

**pytest.ini 配置遗漏**：
- 未声明 `requires_pgvector` marker（虽然 `conftest.py` 中已注册）
- **建议**：将 `requires_pgvector: ...` 加入 `pytest.ini` markers 区块
