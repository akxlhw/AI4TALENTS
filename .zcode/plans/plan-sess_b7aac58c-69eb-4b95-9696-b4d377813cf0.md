# 主页预抓取缓存 + 进度显示方案

## 需求
1. 后台异步批量抓取主页 HTML 并缓存，有进度显示
2. 缓存长期有效，重新导入时清空重建

## 数据层（1 个迁移 + 模型改 2 处）

### 迁移 `053_add_homepage_cache.py`
- `lab_talent` 加两列：`homepage_cache` (Text, nullable) + `homepage_cached_at` (DateTime, nullable)
- `down_revision = '052_add_lab_info_table'`

### 模型 `lab_talent.py`
- 加 `homepage_cache = Column(Text, nullable=True)`
- 加 `homepage_cached_at = Column(DateTime, nullable=True)`

## Service 层（2 个改动）

### `HomepagePreviewService` — 新增 `prefetch_all` 方法
```
prefetch_all(parent_lab, progress_callback) -> dict
  1. 查所有有 homepage 且 homepage_cache IS NULL 的 talent（该 parent_lab 下）
  2. 逐个调 fetch_preview(talent.homepage)
  3. 成功的写入 homepage_cache + homepage_cached_at
  4. 每处理 N 个，调 progress_callback(processed, total, current_name)
  5. 单人超时 10s，失败跳过继续（不中断）
  6. 返回 {total, fetched, skipped}
```

### `LabTalentService.get_homepage_preview` — 改为先读缓存
```
1. 查 talent.homepage_cache + homepage_cached_at
2. 有缓存 → 直接返回 {html: cache, status: "ok", ...}（秒回）
3. 无缓存 → 实时抓取（现有逻辑）+ 写入缓存
```

### 导入清空缓存
- `import_jsonl` 用的是全量替换（DELETE + INSERT），新插入的行 homepage_cache 自然是 NULL
- 所以"重新导入清空缓存"是自动行为，不需要额外代码

## API 层（新文件 `app/domains/lab/api/prefetch.py`）

照搬 genealogy 模式，包含：

### 模块级状态
```python
PREFETCH_STATUS_KEY = "lab_homepage_prefetch_status"
DEFAULT_STATUS = {"status": "idle", "processed": 0, "total": 0, "current": "", "errors": 0}
```

### 端点
- **POST /lab/prefetch-homepages** — 触发后台预抓取（require_admin）
  - 参数：`parent_lab`（必填，指定要预抓取哪个实验室）
  - 如果已在运行 → 409
  - 用 `asyncio.create_task` 启动后台协程
  - 后台协程 `AsyncSessionLocal()` 开独立 session，调 `prefetch_all`，用 ConfigService 存进度

- **GET /lab/prefetch-homepages/status** — 查进度
  - 返回 `{status, processed, total, current, errors}`

### 注册
- `api/__init__.py` 加 `include_router(prefetch.router)`

## 前端（2 个改动）

### 导入完成后自动触发预抓取
- `lab-import-tab.tsx`：导入报告返回后，自动调 POST /lab/prefetch-homepages，并展示进度轮询

### 详情页预览改为读缓存
- `lab-talent-detail-page.tsx`：现有"加载预览"按钮不变，但后端现在优先从缓存返回（秒回）

## 不做的事
- ❌ 不做缓存过期时间（你说长期有效，除非重新导入）
- ❌ 不做全量预抓取（只预抓取有 homepage 且未缓存的人才）
- ❌ 不做并发抓取（逐个抓，避免对目标站点 burst 请求）
